# ANEX Advisory

Premium real-estate advisory website built with Next.js, React, TypeScript and custom CSS.

## Routes

- `/` — Home
- `/services` — Services
- `/services/capital-markets` — Capital Markets
- `/services/redevelopment` — Redevelopment
- `/services/sales-marketing` — Sales & Marketing
- `/projects` — Projects
- `/locations` — Locations
- `/about` — About + Leadership
- `/insights` — Insights
- `/contact` — Contact

All editorial copy is centralized in `content/site.ts`. The visual system follows the supplied ANEX reference: near-black surfaces, editorial serif typography, warm gold accents, architectural imagery, glass cards and subtle 3D pointer interaction.
